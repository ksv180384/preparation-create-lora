# Правила для ИИ-агентов

## Git

Не выполнять никаких операций Git до, во время или после правок без отдельного явного разрешения пользователя на конкретную операцию. Это включает чтение status/diff/log и любые add/commit/push/pull/fetch/checkout/switch/branch/merge/rebase/reset/stash/clean/tag/init/config.
Не изменять .git напрямую и не обходить правило через IDE, API или инструменты веток/PR.
Просьба выполнить задачу или исправить код не разрешает Git. Старые требования коммита в документации и Trello не отменяют это правило.
После работы оставить изменения в файлах и описать результат. Не запрашивать разрешение на Git как обязательный шаг завершения задачи.

## Структура

Код: src/api (Laravel), src/web (Vue), src/worker (Python), src/realtime (Fastify/Socket.IO).
Инфраструктура, compose.yaml, contracts, profiles, scripts и docs остаются в корне.
Не добавлять код в старые заготовки apps/ и services/. Целевая структура — в README.md.

## Работа

Читать PLAN.md, соответствующие спецификации и PROGRESS.md. Сохранять пользовательские изменения. Не отмечать непроверенную работу выполненной.
