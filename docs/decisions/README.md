# Принятые решения — 12 ноября 2026

## ADR-001: Laravel и границы сервисов

Принято. Laravel — модульный монолит, единственный владелец БД и публикации файлов.
Python — специализированный worker, Node/Fastify — доставка Socket.IO.
Причина: единые транзакции и правила версий. Цена: дополнительные HTTP-контракты.
Альтернатива прямой записи Python в БД отвергнута из-за обхода доменных правил.

## ADR-002: PostgreSQL-очередь и outbox

Принято. PHP — database queue Laravel; Python — ProcessingJobItem/lease; события — outbox.
Причина: одна транзакционная система в локальном приложении. Цена: реализовать claim/reaper/fairness.
Redis/Horizon, Kafka, Celery не требуются сейчас; пересмотр при измеренной нехватке производительности.

## ADR-003: Файловая система WSL

Принято. Неизменяемые originals, изолированные attempts, публикация Laravel через private staging.
Причина: локальные папки и атомарный rename на одной ФС. Цена: согласованный backup БД и файлов.
MinIO/S3 отложены; переход потребует нового протокола публикации и миграции.

## ADR-004: Внешние AI и GPU

Принято. LM Studio/ComfyUI на Windows, адрес через UI, запросы из Python-контейнера.
GPU concurrency=1 для всех коллекций; uncertain-запрос блокирует слепой retry.
Цена: отдельная доступность сервисов и контроль резидентной VRAM; очередь не выгружает модели сама.
Автоскачивание моделей и облачная отправка не включаются по умолчанию.

## ADR-005: Локальный владелец

Принято. Single-owner session, CSRF, owner-check, отдельные service tokens и loopback gateway.
Причина: локальный сценарий; не добавлять регистрацию/команды. Цена: сеть общего доступа
и многопользовательский режим требуют нового решения. Localhost не отменяет защиту API.
